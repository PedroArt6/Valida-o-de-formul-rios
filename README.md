# Validação de formulários 

O projeto usou uma base de código já pronta e foi implementada uma opção de seleção obrigatória de cursos, a validação usa operadores condicionais e valida nome, email, curso escolhido, senha e confirmação de senha. Tudo isso dentro de um formulário, usando value e useStat.
A navegação entre páginas usou reactRouter, que permite mudar os elementos de uma página sem recarregá-la.

Tecnologias utilizadas: React, Vite e node js.

#### Para rodar a aplicação, use:

> cd portal-cursos

> npm install

> npm run dev
